전 챕터를 다시 검수한 완성판입니다.

**원본 유럽판 이미지에 적용하는 전체 패치입니다.** 이전 버전을 적용한 이미지에는 적용할 수 없습니다.

## 변경 사항

- 전 챕터 대사와 조사할 때 나오는 혼잣말, 장 요약, 세이브 줄거리, 인물·아이템 설명, DAS 메일을 처음부터 끝까지 다시 검수했습니다. 일본어 직역투를 고치고 문장 사이를 매끄럽게 이었습니다.
- 짧은 맞장구와 감탄사가 같은 말로 되풀이되던 곳을 장면에 맞게 다듬었습니다.
- 인물마다 말투와 호칭을 원작 관계에 맞게 정리했습니다. 이름으로 부르는 원작대로 덧붙였던 호칭을 빼고, 매슈는 애슐리를 「누나」라고 부릅니다.
- 세이브를 불러올 때 나오는 줄거리의 줄바꿈을 화면에 맞게 다시 나누고, 문장 사이에 끼던 빈 줄을 없앴습니다.
- 엔딩 등장인물 소개와 인물 소개 카드에 남아 있던 개 이름을 「프린세스」로 고쳤습니다.
- 문장부호와 띄어쓰기를 다듬었습니다.
- 여러 인물의 말투와 대사 몇 줄의 번역을 다듬었습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `RNOP_KPatch_v1.0f.zip` | 원본 유럽판(ISO·WBFS) | 한글 패처. 사용자 설명서 포함. |

## 지원 형식

| 원본 | 결과 |
|---|---|
| ISO (정본 덤프, WBFS에서 변환한 ISO 등) | ISO |
| WBFS | WBFS |
| CISO, WIA, WDF | ISO |
| RVZ · NKit | 지원 안 함. ISO로 변환·복원한 뒤 적용 |

덤프·변환 방법에 따라 MD5가 달라도 게임 파일만 같으면 적용됩니다.

## 적용 방법

1. zip을 풀고 원본 이미지(ISO 또는 WBFS)를 `패치하기.bat` 위에 끌어다 놓습니다. 원본을 같은 폴더에 넣고 더블클릭해도 됩니다.
2. `완료`가 나올 때까지 기다립니다(1분에서 2분 정도).
3. 원본과 같은 폴더에 결과 파일이 생깁니다.
   - ISO 원본 → `Another Code R (Korean) [RNOP01].iso`
   - WBFS 원본 → `Another Code R (Korean) [RNOP01].wbfs`

결과 형식을 바꾸려면 패처 폴더의 PowerShell에서 `powershell -ExecutionPolicy Bypass -File patch.ps1 "원본.iso" "결과.wbfs"`처럼 결과 확장자를 지정합니다.

UWUVCI로 Wii U에 주입할 때는 영상 모드 패치(PAL to NTSC)를 끄세요. 이 게임은 유럽판이어도 60Hz로 실행됩니다.

패처가 파일마다 적용 전후 MD5를 검사합니다. 결과 이미지의 MD5는 원본 덤프에 따라 달라질 수 있지만 게임 내용은 같습니다. 오류 메시지와 해결 방법은 동봉한 `README_한국어.txt`를 참고하세요.
